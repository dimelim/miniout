# Contributing

Issues and PRs welcome. App UI is Spanish only right now. Issues may be Spanish
or English.

## Rules

- No comments in the code. If a line needs an explanation, the fix is a better
  name.
- No em dashes and no emojis in code, UI, docs, or commit messages.

## Setup

```bash
npm install && npx expo start
```

npm test covers the date/subject parser.
npm run typecheck runs tsc.
Read the Expo SDK 57 docs (see AGENTS.md).

## Pull requests

Say what changed and how you checked it. Do not reformat files you did not touch.
